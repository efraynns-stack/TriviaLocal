# Trivia Local

Trivia multijugador para Android TV y Google TV. La TV aloja la partida y los jugadores responden desde el navegador de su teléfono en la misma red local.

- **Cargar PDF** en la sala genera un QR para importar desde un teléfono. Usa un PDF de texto con preguntas numeradas, cuatro alternativas A–D y una respuesta marcada con ✓ o una línea `Respuesta: B`.
- **Buscar actualizaciones** en la TV consulta las versiones públicas de este repositorio. Android solicita confirmación antes de instalar.

Descarga el APK desde **Releases**.
